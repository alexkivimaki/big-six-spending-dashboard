# Source Policy For Financials

## Preferred source hierarchy

1. Official club annual reports or financial statements
2. Companies House filings
3. SEC filings for Manchester United
4. Official investor relations pages
5. Club official financial result announcements
6. Deloitte reports for cross-checking only
7. Reliable journalism only for context, not primary values

## Rules

- Do not use unsourced fan sites as primary sources.
- Always store the source URL, document title, and date accessed.
- Always flag uncertainty.
- If multiple entities exist, document why the selected entity is the most relevant football reporting perimeter.
- Treat cross-check sources as validation aids, not replacements for primary filings.
